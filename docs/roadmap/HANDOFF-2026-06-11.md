## 5. Operational notes / landmines (the expensive ones)

- **Railway CLI:** always pass `--service flipops-site|worker-bullmq` (bare `railway service` opens an interactive TUI that hangs). Deploy status: `railway deployment list --service <svc> --json | node -e '...'` (the `node -e` JSON parse is finicky in bash loops — write the parser to a `/tmp/*.js` file and pipe to it; inline `node -e` with nested quotes breaks).
- **prisma:** `db push` only, NEVER `migrate dev` (drift wipes Railway data). Sequence: edit schema → push → generate → THEN code against new models. `generate` fails with EPERM if a dev server / running script locks the query-engine DLL — kill node procs first.
- **DATABASE_URL** must be exported from `.env.local` for any script: `export DATABASE_URL=$(grep '^DATABASE_URL=' .env.local | sed 's/^DATABASE_URL=//; s/^"//; s/"$//')`.
- **Big UPDATEs must be chunked** (~150K rows/statement) — Railway's TCP proxy kills silent long statements ("Server has closed the connection"). See `scripts/derive-owner-occupancy.ts --chunk-size`.
- **Scrapers:** govhub/TaxSys are residential-egress-only (OPS-6); Broward Acclaim needs stealth-chromium+residential proxy (CF blocks else); Duval Acclaim is pure-undici direct; RealAuction = `useProxy:false` direct. RealAuction pins auction date at cookie-mint (fixed this session — cookies per county+date).
- **Workflow tool:** rejects literal `Math.random()`/`Date.now()`/`new Date()` substrings anywhere incl. agent prompt strings. `git add -A` after agent waves can sweep in tmp debris — check `git status` before committing.
- **Commit messages with apostrophes** break bash heredocs → use `git commit -F <file>` or a heredoc with no apostrophes.
